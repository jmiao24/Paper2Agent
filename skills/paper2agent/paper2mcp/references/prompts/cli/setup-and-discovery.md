# CLI environment and tool selection

Follow the [shared stage](../setup-and-discovery.md), [CLI route](../../routes/cli.md), and [orchestration](../../orchestration.md). Use the specialists linked by the route and its native runtime/transport requirements.

Use the route's environment manager and scanner concurrently. Record source bindings, useful tools, scope/filter decisions, native runtime readiness, and blockers in the shared report/state contracts.

All command tools share one cli_wrapper module with one implementer and one separate verifier. Invoke the configured scientific executable with bounded arguments.
